# Excel Pricing Engine

An advanced Excel workbook built for a real 24-unit commercial kitchen job. Took what normally required an expert multiple days to calculate and compressed it into a structured, automated tool anyone can use.

---

## The Problem

Pricing a large commercial kitchen job means tracking dozens of unit types, material costs, labour rates, hardware counts, and delivery timelines — all at once. Done manually in a basic spreadsheet, it's a multi-day job that's easy to get wrong.

---

## What It Does

- **7 interconnected sheets** covering materials, labour, hardware, markup, and totals
- - **VLOOKUP-powered pricing** — change a base cost in one place, everything updates
  - - **Dynamic arrays** for flexible unit configurations
    - - **Dropdown menus** for consistent, error-free data entry
      - - **Integrated Gantt calendar** for project scheduling and milestone tracking
       
        - ---

        ## Tech Stack

        `Microsoft Excel` — Advanced formulas, VLOOKUP, dynamic arrays, data validation, conditional formatting

        ---

        ## Why This Matters

        This wasn't a tutorial project. It was built under real deadline pressure for a real commercial job. The fact that it worked — and saved days of manual work — is the proof of concept.
